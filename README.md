# Linux Stewards

Linux Stewards is a UK-based technology services business. We help people and organisations fix, build and improve websites, software, computers, servers and everyday technical workflows.

Remote help is available worldwide where appropriate, and small jobs are welcome.

## Services

- Website development, repairs and changes
- WordPress, Next.js and React
- Software development and Python
- Windows, Mac and Linux support
- Server, network, DNS, domain and email administration
- Office automation, spreadsheets, data, PDFs and document work
- AI integration, business automation and mobile applications
- Technical troubleshooting
